NOVIA (Noviris) is a feature-rich React Native application designed specifically for couples to stay connected, organized, and engaged with each other on a daily basis.

## ✨ Features

- **💑 Relationship Milestones:** Track anniversaries and special dates with push notifications so you never forget!
- **📅 Daily Check-ins & Streaks:** Share how you're feeling every day and build streaks together.
- **💬 Complaint Threads:** A healthy space to voice and resolve disagreements.
- **✅ Shared Todos:** Manage shared tasks with a beautiful time picker and real-time push notifications.
- **💰 Finance Tracker:** Keep tabs on shared expenses and track your couple finances seamlessly.
- **🩸 Cycle Tracker:** Integrated period and ovulation predictions using custom cycle math.
- **📚 Daily Vocabulary:** Learn 40+ new words daily together.
- **🔄 Realtime Sync & OTA Updates:** Built on Supabase for instant data sync, and Expo EAS for seamless over-the-air updates without app store reinstalls!

## 🚀 Getting Started

### Prerequisites
- Node.js & npm
- Expo CLI
- Supabase Project

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your environment variables:
   - Copy `eas.example.json` to `eas.json` and fill in your Supabase URL and Anon Key.
   - Copy `.env.example` to `.env`.
4. Start the development server:
   ```bash
   npm start
   ```

## 🛠 Tech Stack
- **Framework:** React Native / Expo
- **Backend:** Supabase (PostgreSQL, Realtime, Auth)
- **Notifications:** Expo Push Notifications
- **Build & Deploy:** EAS Build & Update
